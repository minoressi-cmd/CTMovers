# Photos go here

Drop files in with these exact names. The site picks them up automatically and hides the placeholder.

```
hero-1.jpg   hero-2.jpg   hero-3.jpg        top-of-page polaroids (landscape)
job-1.jpg    job-2.jpg    job-3.jpg         "Recent jobs" gallery
job-4.jpg    job-5.jpg    job-6.jpg         (job-1 tall, job-5 wide, rest square-ish)
crew-1.jpg   crew-2.jpg   crew-3.jpg        crew headshots (square)
crew-4.jpg
og-image.jpg                                 link preview, 1200x630
```

`.jpg` is what the HTML expects. If you have `.png` or `.heic`, either convert them or change the filename in `index.html`. Keep each under ~400 KB.
